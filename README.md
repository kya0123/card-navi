# card-navi
使用店舗を入力するとおすすめの決済カードをリコメンドする

| フォルダ | 内容 |
|---|---|
| `app/` | PWA本体（ソース・テスト・ビルドスクリプト）。詳細は [app/README.md](app/README.md) |
| `design/` | 設計書（基本設計・詳細設計・判断記録・収益化設計・試験報告） |
| `master/` | 還元ルールマスタの生成スクリプトと出典調査 |

`main` の `app/dist/`（`npm run build` の出力）が GitHub Pages に公開されます（`.github/workflows/deploy.yml`）。
